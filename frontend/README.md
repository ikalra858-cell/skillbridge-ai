# SkillBridge AI — Frontend

This directory contains the frontend application for **SkillBridge AI**, a career-focused skill assessment and personalized learning roadmap platform.

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router

## Getting Started

From this directory, install dependencies and start the development server:

```bash
npm install
npm run dev
```

To configure the backend API URL, create a `.env` file in this directory:

```env
VITE_API_URL=http://127.0.0.1:8000
```

Ensure the FastAPI backend is running and configured to allow requests from the frontend origin.

For complete project setup instructions, features, and architecture, see the [main README](../README.md).
